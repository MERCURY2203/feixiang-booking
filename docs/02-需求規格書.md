## 訂場首頁

客人在這一頁選日期、選格子、一次付清；表格橫向是場地 1–10 號（左右滑），直向是時間 9:00–23:00（上下滑）。

**版面（從上到下）**

1. 橫幅輪播（最多 5 張，每張 10 秒）
2. 日期條：7 個營業日（今天未打烊則含今天，已打烊則從明天起數；全天休息的日子跳過、不顯示），每天只顯示日期和星期，如「11/05 周三」；週末和節假日不另作標註
3. 場地 × 時段表格：場地號一行凍結在頂部、時間一列凍結在左邊，滑動時不會滑走
4. 右下角圓形購物車浮窗：顯示件數，點擊進入購物車頁
   - 浮窗可收到右邊：往右滑浮窗，或點它左上角的小箭頭，縮成貼著右邊緣的小標籤（仍顯示件數，G2 仍滿足）；點小標籤或往左滑展開；收起狀態會記住（2026-11-06 定案）

**格子狀態**

| 狀態 | 顏色 | 格內文字 | 能否點選 |
| --- | --- | --- | --- |
| 可訂 | 白色 | 價格，如 ¥65.00（淡灰色細字，避免整張表過於密集；2026-11-06 定案） | 能 |
| 我已選 | 藍色 | 價格 | 能（再點取消選擇） |
| 我訂的（已付款） | 淺藍底、藍色邊框 | 「我的」（2026-11-06 定案，讓客人一眼看出哪幾格是自己訂的） | 不能 |
| 我的待支付訂單佔著的 | 淺藍底、藍色虛線邊框 | 一個沙漏 ⏳（避免誤以為被別人搶先訂了；點一下提示「这格是你的待支付订单，请尽快支付」） | 不能 |
| 已被訂（含別人待支付中） | 淺灰色（與「已過去」「鎖場」完全一致） | 畫一個叉 ✕（不寫字；2026-11-06 定案，讓客人一眼看懂） | 不能 |
| 老闆鎖場 | 淺灰色（同上） | 畫一個叉 ✕ | 不能 |
| 已過去 | 淺灰色（同上） | 畫一個叉 ✕（所有訂不了的格子底色、叉的顏色完全一致；2026-11-06 定案） | 不能 |

**選格與下單規則**

- 點擊可訂格子即加入購物車（變藍色），再點一次移出；可與活動商品一起付清。購物車最多 40 項（一格場地或一種商品算一項），滿了提示「购物车最多 40 项，请先结算或删除一些」（2026-11-05 定案，與一張訂單的上限相同）
- 別人待支付中的格子顯示為打叉；5 分鐘後若對方未付款、訂單關閉，格子自動恢復「可訂」
- 客人已選的格子如果在付款前被別人搶先下單，提交時提示「部分场次已被预订」，並自動取消選中那幾格，其餘保留
- 切換日期時，已選的格子保留，可跨日期一起下單

**與訂單相關的決定**（細節寫在「我的」→ 訂單詳情）

- 多格訂單可以只取消其中幾格，每格各自按「開場前 15 分鐘之前」判斷能否取消
- 取消的格子按該格實付金額退款，訂單狀態變為「部分退款」
- 取消規則在結算時彈窗告知（見「下單、待支付與支付結果」），訂單詳情頁也會顯示

**驗收標準**

- [ ] 5 種格子狀態顏色和文字與上表一致
- [ ] 左右、上下滑動時，場地號和時間始終可見
- [ ] 選格、取消選格、切換日期後，表格停在原位置（G1）
- [ ] 購物車浮窗始終可見，件數即時更新（G2）
- [ ] 往右滑浮窗或點小箭頭，浮窗縮到右邊緣；點小標籤展開；切到別的頁面再回來，狀態保持
- [ ] 另一部手機下單待支付時，本機該格即時打叉；5 分鐘未付後恢復可訂
- [ ] 23:30 打開時自動顯示明天（G5）

## 購物車

場地和活動商品統一放進購物車，一張訂單一次付清；取代原來的「已选」功能。

**浮窗**

- 圓形浮窗，固定在訂場首頁和活動頁的右下角，不隨滑動移動
- 浮窗上用數字角標顯示購物車內件數
- 表格和商品列表底部留出空白，最後一行可滑到浮窗上方，不會被擋住

**購物車頁**

- 分「场地」「活动」兩組
- 場地每行：日期、場地、時間、金額、刪除
- 商品每行：名稱、單價、數量加減、小計、刪除
- 底部固定：「清空」、合計金額、「去结算」

**規則**

- 購物車存在手機緩存：關閉小程序後保留；換手機或清緩存後清空
- 購物車最多 40 項；每種商品一次最多 99 張
- 加入購物車**不會鎖場**；按「去结算」建立訂單時才鎖定
- 場地格子已過去或已被別人訂、商品已下架或庫存不足 → 標為「已失效」（灰色），不計入合計，結算時自動排除
- 退款仍按每格場地、每張券各自處理
- 失效項目一直保留（灰色），直到客人刪除；購物車頂部出現「清除失效项」按鈕；固定日期活動過了開始時間同樣變失效
- 付款成功後，已買的項目自動從購物車移除
- 購物車永遠顯示最新價格；按「去结算」時如有價格變動，先彈窗「以下价格已变动」列出新舊價格和新合計，按「我知道了」才繼續
- 同一客人同時只能有一張待支付訂單；再結算時提示「你有一笔待支付订单」，可選「去支付」或「取消旧订单」

**驗收標準**

- [ ] 訂場首頁和活動頁都看得到浮窗，件數與購物車一致
- [ ] 在購物車刪除一格場地，返回訂場首頁該格變回白色，表格位置不變
- [ ] 關閉小程序再打開，購物車內容仍在
- [ ] 購物車內的格子被別人訂走後，顯示「已失效」且不計入合計
- [ ] 購物車已有 40 項時，再點格子或加購商品提示「购物车最多 40 项」，原有內容不變
- [ ] 場地和商品同一張訂單付款成功，各自生成訂場記錄和券

## 下單、待支付與支付結果

不設確認訂單頁：在購物車頁按「去结算」即建立訂單、開始 5 分鐘計時，並直接彈出微信付款。

**流程**

1. 客人在購物車頁按「去结算」（或在商品詳情頁按「立即购买」）
2. 訂單內有場地時，彈窗告知羽毛球場退款規則（开场前15分钟前可取消并全额退款），只有一個按鈕「我知道了」；純活動商品訂單不彈此窗
3. 接著連續彈出：微信授權手機號（只對未授權過的客人）、訂單通知授權（勾過「总是保持」的不再彈）；手機號拒絕則提示「必须授权手机号才可下单购买哦」，流程停止；通知授權拒絕不影響下單
4. 系統檢查購物車內的格子是否仍可訂、商品庫存是否足夠
   - 有格子已被搶或庫存不足：提示「部分场次已被预订」或「库存不足」，標為已失效，留在購物車頁，不建立訂單
   - 全部可用：建立訂單（狀態「待支付」），鎖住格子和庫存，開始 5 分鐘計時
5. 自動彈出微信付款窗
6. 付款成功 → 支付結果頁；未付款關掉付款窗 → 待支付頁

**待支付頁**

- 頂部：5 分鐘倒計時（顯示如 04:59），下方一行「请在此时间内完成支付」
- 中間：訂單明細（每格的日期、場地、時間、金額）和合計
- 底部固定兩個同樣大小的按鈕並排：左邊「取消订单」（紅框紅字，醒目）、右邊「继续支付」（藍底白字）；按「取消订单」先彈窗「确定取消订单？」，確認後格子和庫存立即放出
- 倒計時歸零 → 按「訂單關閉的定義」處理（見立項書），頁面顯示「订单已关闭」和「返回订场」按鈕
- 從「我的訂單」點進待支付訂單，也進入這一頁

**支付結果頁**

- 成功：顯示「预订成功」、訂單明細、「查看订单」「继续订场」兩個按鈕
- 確認中（聯絡不上微信時）：顯示「正在确认支付结果…」，自動重試，有結果後自動更新

**手機號**

- 首次打開小程序、同意協議時請求微信授權手機號；拒絕也可以瀏覽場地和活動。按「去结算」或「立即购买」時若仍未授權，主動彈出授權請求；客人拒絕則提示「必须授权手机号才可下单购买哦」，不建立訂單

**驗收標準**

- [ ] 按「去结算」後 1 秒內彈出微信付款窗
- [ ] 關掉付款窗後停在待支付頁，倒計時繼續，與伺服器時間一致
- [ ] 待支付頁按「继续支付」可再次彈出付款窗
- [ ] 按「取消订单」後格子立即恢復可訂
- [ ] 倒計時歸零後訂單變「已關閉」，格子恢復可訂
- [ ] 第 4 分 59 秒付款成功，訂單成立

## 活動

活動頁以長方形卡片列出商品，可在列表直接加購，也可進詳情頁「立即购买」或「加入购物车」。

**商品列表**

- 每個商品一張長方形卡片，一行一張，圖片佔滿寬度
- 卡片上方是商品圖片，圖片下方是價格條：左邊價格，右邊「加入购物车」按鈕
- 每按一次「加入购物车」數量 +1，浮窗角標即時更新，頁面位置不變
- 點卡片其他位置進入商品詳情頁
- 已售罄的商品：按鈕變灰，顯示「已售罄」

**商品詳情頁**

- 內容：圖片（可多張滑動）、名稱、價格、庫存剩餘、有效期（固定日期或長期）、說明文字、數量加減
- 後台上傳商品圖片時，每張選好後依序進入裁剪畫面，手動調整 4:3 的範圍；詳情頁大圖按 4:3 顯示，活動列表和後台縮圖取中間一塊顯示（2026-11-06 定案）
- 底部一條懸浮欄：左邊一小塊顯示價格（隨數量顯示小計），右邊並排「立即购买」「加入购物车」
- 詳情頁不顯示圓形購物車浮窗，避免與底部懸浮欄重疊；返回列表後可見角標
- 「立即购买」：不經購物車，直接以所選數量建立訂單，進入 5 分鐘待支付流程；購物車內容不受影響
- 「加入购物车」：按所選數量加入購物車，停留在詳情頁

**驗收標準**

- [ ] 列表按「加入购物车」後角標 +1，頁面不跳動
- [ ] 庫存為 0 的商品不能加購、不能購買
- [ ] 數量加減不能超過庫存，也不能小於 1
- [ ] 「立即购买」付款成功後，購物車原有內容仍在
- [ ] 底部懸浮按鈕在滑動說明文字時始終可見

## 我的

「我的」頁包含個人資料、我的訂單和退款入口；訂單按狀態分頁，訂單內每個場地時段、每件商品各是一張卡片。

**頂部個人資料**

- 客人可一鍵使用微信頭像和暱稱，也可以自己換頭像、改暱稱
- 未設定頭像暱稱時，只顯示手機號，中間 4 位隱藏，如 138\*\*\*\*5678

**我的訂單**

| 分頁 | 顯示 |
| --- | --- |
| 全部 | 所有訂單 |
| 待支付 | 5 分鐘內還沒付款的訂單；訂單卡片上直接顯示倒計時和「取消订单」「去支付」兩個按鈕 |
| 待使用 | 已付款，還有未打的場或未用的券 |
| 已完成 | 全部打完、用完 |
| 退款 | 有退過款的訂單（含部分退款） |

**訂單列表卡片（客人的「我的订单」、後台訂單管理）的明細寫法**（2026-11-06 定案，統一格式）

- 場地：按日期分組，組頭一行日期；每個時段單獨一行，左邊寫時段、右邊寫場號，如「18:00–19:00　　1号场」，依時間、場號排序
- 活動商品：同一種商品合併成一組，寫商品名稱，右上角一個圓圈寫件數，如「×3」
- 後台（老闆、員工）的訂單卡片不合併、單獨顯示：每個場地時段一行「日期 時段　　場號」，每種商品一行（2026-11-06 定案）
- 舊訂單沒有明細時，把原來的摘要拆成一行一項，不顯示圓圈
- **訂場和活動分開成各自的卡片**（2026-11-06 定案）：訂場和活動不是同類產品，即使在同一次結算、同一次付款，列表也分開顯示——所有場地時段一張卡片（金額是場地小計），每種活動商品各一張卡片（金額是該商品小計）；每張卡片樣式相同，都有下單時間、狀態、自己的明細和金額，點任何一張都進同一筆訂單的詳情
- 待支付的訂單同樣分成多張卡片，但付款只有一次：「剩余 mm:ss」每張都顯示，「取消订单」「去支付」只出現一組，放在最後一張卡片底下，旁邊標「待付合计」
- 舊訂單沒有各項金額，不拆，仍是一張卡片

**狀態定義**

- 訂單狀態：待支付、已取消（待支付時客人取消）、已關閉（5 分鐘未付）、待使用、已完成、部分退款、已退款（全部退完）、超時已退款
- 場地卡片：待使用 → 該小時結束後自動變「已使用」；或「已退款」
- 商品卡片：按張數顯示未使用、已核銷、已退款、已過期
- 已完成：所有卡片都已使用、已核銷、已退款或已過期；長期商品沒用完的，訂單一直留在「待使用」

**訂單詳情頁**

## 管理端

老闆和員工從「我的」→「管理后台」進入；左上角選單按鈕打開側邊欄切換功能，進入後客人端底部分頁隱藏。

**老闆綁定**（系統只有一位老闆）

- 主路：開發者在雲開發後台執行工具，產生一次性老闆二維碼（24 小時有效），老闆掃碼即綁定，碼隨即作廢
- 備用路：開發者在後台登記老闆的手機號；老闆打開小程序並授權該手機號時，自動成為老闆
- 換老闆：開發者重新產生老闆碼或改登記手機號，舊老闆身份自動移除

**側邊欄**

- 按權限只顯示自己能用的功能（見「頁面地圖」權限表）
- 最下方「返回客人模式」
- 選擇功能後側邊欄自動收起

### 核銷（管理端首頁）

- 上方一個大的「扫码核销」按鈕
- 下方輸入框，可手動輸入 6 位碼
- 掃碼或輸碼後彈窗：商品名稱、客人手機號、可用張數、選擇核銷張數、「确认核销」
- 頁面上有「核销记录」按鈕，點開查看詳細記錄：時間、商品、張數、客人手機號、操作人
- 核銷記錄可「撤销」：只限當天的記錄，撤銷後張數退回「可用」，並留下撤銷記錄（誰、何時）
- 場地訂單不需核銷或簽到

**驗收標準**

- [ ] 掃碼後 1 秒內彈出券資料
- [ ] 核銷張數不能超過可用張數
- [ ] 核銷後客人訂單詳情的卡片張數即時更新
- [ ] 當天記錄可撤銷，前一天的記錄沒有「撤销」按鈕
- [ ] 撤銷後記錄裡同時看得到原核銷和撤銷兩筆

### 訂單管理（老闆、員工）

- 頂部搜索框：輸入手機號後 4 位或訂單號
- 篩選：日期、狀態（待支付／待使用／已完成／退款）
- 列表每行：下單時間、內容摘要、金額、狀態；點進去看訂單詳情（與客人看到的卡片一致）
- 客人電話中間 4 位隱藏；按「查看电话」顯示完整號碼並留下查看記錄（誰、何時），號碼可直接點擊撥打
- 管理端退款不受「開場前 15 分鐘」限制，任何時候都可以退；每張卡片各自退，退款前同樣有確認彈窗
- 可退部分金額：退款彈窗預填該卡片剩餘可退金額，可手動改小；同一卡片可多次退款，累計不超過該卡片實付金額
- 每筆管理端退款記錄操作人和時間
- 管理端可多選卡片一次退款（合併為一筆微信退款）
- 微信限制每張訂單最多退款 50 次：某訂單已退 45 次起，管理端打開該訂單時提示「此订单剩余退款次数 N 次，请合并退款」；客人端該訂單的「退款」改為「请联系球馆退款」
- 兩人同時退同一張卡片：系統保證只退一次，後按的人看到「该项已退款」

**驗收標準**

- [ ] 輸入手機號後 4 位能找到該客人所有訂單
- [ ] 開場後仍可在管理端退款
- [ ] 每按一次「查看电话」都在記錄裡多一筆
- [ ] 員工退款後，老闆能在記錄裡看到是哪位員工操作
- [ ] ¥65.00 的卡片先退 ¥32.50，再退 ¥32.50 成功；第三次退款被拒絕並提示已無可退金額

- [ ] 已退 45 次的訂單出現剩餘次數提示

### 場地管理（老闆、員工）

**驗收標準**

- [ ] 已有訂單的格子無法鎖定，並有提示
- [ ] 多選 5 格一次鎖定，5 格同時生效
- [ ] 鎖定或解鎖後表格停在原位置（G1）

### 商品管理（老闆、員工）

- 新增／編輯商品填寫：名稱、圖片（最多 6 張）、價格、庫存、說明文字、類型（固定日期／長期）、上架／下架開關
- 固定日期商品：需填活動日期和開始時間；客人可自行退款至開始前 15 分鐘；活動當天 23:59 後過期，未使用的張數自動全額退款
- 長期商品：永不過期；老闆可隨時在訂單管理對未使用的張數全額或部分退款（例如漲價後）

- 已有人買過的商品不能刪除，只能下架；下架後客人看不到、不能買，已購買的券照常可用

**驗收標準**

- [ ] 改價後，舊訂單金額不變

  - 長期顯示：一直顯示，直到手動下架
  - 限時顯示：設定開始和結束時間，到時自動上架、自動下架

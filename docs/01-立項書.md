## 重做原因與上一版問題

上一版是邊想邊做，很多細節沒有事先寫清楚，導致 bug 多、體驗差。這次每個問題都對應一條規則，並寫進驗收標準。

| 上一版的問題 | 原因 | 這次的做法 |
| --- | --- | --- |
| bug 特別多 | 沒寫清楚「怎樣才算做對」，做完也沒逐項檢查 | 每個功能先寫驗收標準，做完一塊就檢查一塊 |
| 要重複找按鍵 | 沒事先規劃按鍵位置 | 第 2 步畫出每頁佈局，重要按鍵固定位置 |
| 每點一下都跳回頂部 | 每次操作都重新載入整頁 | 操作後停留原位置，列入每頁驗收標準 |
| 沒有待支付狀態 | 訂單只有已付款和已取消 | 設計完整的訂單狀態（見「本次已定案的決定」） |
| 我的訂單看不到待支付訂單 | 同上 | 待支付訂單在「我的訂單」可見，可繼續付款或取消 |
| 營業時間外打開全是灰格，無法訂場 | 用「現在是否營業」判斷所有日期 | 只有已過去的時段變灰；今天結束自動跳到明天，未來 7 天照常可訂 |
| 小數價格顯示錯誤（88.5.00） | 已有小數點的數字又被加上「.00」 | 金額一律以「分」存儲，顯示時統一轉為兩位小數 |
| 管理員入口在登錄頁 | 客人也看得到管理入口 | 改為自動識別老闆／員工身份 |
| UI 與佈局 | 整體設計不理想 | 全部重新設計 |

## 使用者與範圍

三類使用者共用同一個小程序，系統按微信身份自動區分。

| 使用者 | 主要能做的事 |
| --- | --- |
| 客人 | 查空場、訂場、微信支付、取消訂單、查看訂單、購買活動商品 |
| 老闆 | 全部管理功能：價格、營業時間、鎖場、報表、訂單、退款、員工、商品、橫幅 |
| 員工 | 查訂單、看客人電話、取消退款、鎖場、核銷、商品與橫幅管理 |

**這次要做：** 10 個場地按小時預訂、微信支付、峰谷定價、活動商品與核銷、後台管理。

**這次不做：** 會員儲值卡、教練預約、多館管理。

## 成功標準與項目原則

**成功標準**

- 客人 1 分鐘內能完成一次訂場付款
- 同一場地同一時段絕不會被重複賣出
- 不會出現「錢扣了但沒訂到、也沒退款」
- 老闆每天能看到收入報表

**項目原則**（以後所有決定都要遵守）

1. 不能重複賣出同一個場地時段（最重要）
2. 錢必須準確：金額一律以「分」存儲，每筆付款、退款都有記錄
3. 每一筆訂單都有清楚的狀態，客人和老闆隨時看得到
4. 客人電話號碼要保護：只有老闆和員工能看，查看留痕，最後一次訂場 1 年後自動刪除
5. 操作流暢：按鍵位置固定，操作後不跳頁、不回頂部
6. 畫面簡單，老人家也會用
7. 所有時間以北京時間、伺服器時間為準

## 本次已定案的決定

以下是 2026-11-03 討論中已確定的規則，後續步驟必須照此執行。

**管理員入口（方案 A：自動識別身份）**

- 老闆和員工的微信號登記在系統內；他們打開小程序時，「我的」頁面自動出現「管理後台」按鈕
- 普通客人看不到任何管理入口；登錄頁不設管理員登錄
- 員工加入：老闆產生一次性邀請二維碼（10 分鐘有效），員工用微信掃碼後自動綁定；離職時老闆一鍵移除

**價格**

- 支持到「分」，統一顯示兩位小數，例如 ¥88.55、¥88.50、¥65.00

**待支付與訂單成立**

- 計時起點：系統建立訂單那一刻（退款規則彈窗、授權、檢查都通過後，彈出微信付款前）伺服器記錄的時間；終點：起點 + 5 分鐘（2026-11-04 由 60 秒改為 5 分鐘）
- 待支付期間頁面頂部顯示 5 分鐘倒計時，下方一行提示「請在此時間內完成支付」
- 倒計時只是顯示，以伺服器時間為準
- **訂單成立：** 微信記錄的付款完成時間在 5 分鐘以內（以微信記錄的時間為準，不是系統收到通知的時間）
- 微信支付訂單有效期同樣設為 5 分鐘

**訂單關閉的定義**

- 5 分鐘到期，**而且**微信確認「沒收到錢並已關單」，兩個條件都滿足才算「已關閉」
- 5 分鐘到時，系統先問微信是否已收款：已收款且時間在 5 分鐘內 → 訂單成立；未收款 → 通知微信關單 → 關單成功才關閉並放出場地
- 暫時聯絡不上微信 → 不關閉，客人看到「正在確認支付結果…」，場地繼續鎖住，系統反覆重試直到有結果
- 未確認清楚之前，場地絕不放出

**超時付款的處理（三道防線）**

1. 預防：下單時給微信設定 5 分鐘有效期；到期即向微信關單，之後無法付款
2. 付款通知檢查：收到微信付款通知時，若訂單已關閉 → 一律全額原路退款，狀態改為「超時已退款」，寫入退款記錄
3. 定時對帳：每 5 分鐘向微信查詢最近關閉的訂單，查到有收款的同樣全額退款

- 不論場地是否仍空著，超時付款一律退款（不自動補訂）
- 客人下單時請求「訂單通知」授權；已授權則推送退款通知，未授權則在「我的訂單」顯示「超時已退款」並註明 1–3 個工作日到帳
- 自動退款記錄老闆後台可查

**訂單狀態（第 3 步定稿；卡片狀態見規格書）**

| 狀態 | 何時出現 |
| --- | --- |
| 待支付 | 下單後 5 分鐘內，未付款 |
| 已支付 | 5 分鐘內付款成功 |
| 已完成 | 已支付且打完球 |
| 已退款 | 全部卡片都已退款（客人自退、管理端退或過期自動退） |
| 部分退款 | 部分卡片已退款，其餘仍有效 |
| 已取消 | 待支付期間客人主動取消（同時通知微信作廢） |
| 已關閉 | 5 分鐘內沒付款，系統自動關單 |
| 超時已退款 | 微信記錄的付款時間超過 5 分鐘仍扣款，已全額退回 |

**營業時間外**

- 只有已過去的時段變灰；未來日期照常可訂
- 當天營業時段全部結束時，自動跳到明天

**介面**

- UI 和佈局全部重新設計
- 按鍵位置固定；任何操作後停留在原位置，不跳頁、不回頂部

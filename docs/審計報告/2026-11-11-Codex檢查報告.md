| 問題 | 補測結果 |
|---|---|
| **結算確認後改價，系統會直接按新價下單** | 購物車報價 ¥50，商家在客人確認規則或授權期間改成 ¥90。系統未再顯示差價確認，就建立 ¥90 的支付請求。[購物車](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/miniprogram/pages/cart/index.js#L100) · [下單](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/cloudfunctions/booking/index.js#L182) |
| **微信未建單，逾時後仍鎖場** | 模擬本地已建立訂單並鎖場，但在微信建單前中斷。逾時任務查不到微信訂單後，仍保留待支付與場地鎖，同一客人再次下單會被擋住。[逾時處理](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/cloudfunctions/_shared/orders.js#L315) |
| **較新的異常退款會被前面的退款擋住** | 前 20 筆退款持續處理中時，第 21 筆異常退款在連續 25 次定時執行中都沒被查到，管理端也沒有收到異常通知。[退款查詢排程](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/cloudfunctions/timer/index.js#L65) |
| **失敗的自動退款會耗盡退款次數** | 模擬商戶餘額不足，過期活動券每輪重試都消耗一次額度。50 次均未退成功，餘額恢復後，程式也因達到自身上限而不再送出退款。[過期退款](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/cloudfunctions/timer/index.js#L95) · [次數限制](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/cloudfunctions/_shared/orders.js#L348) |
| **訂場頁會跳回舊日期** | 客人切到新日期後，較早發出的自動刷新如果較晚回來，會把畫面覆蓋回舊日期。接著點格子，選到的就是舊日期的場地。[訂場頁](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/miniprogram/pages/booking/index.js#L69) |
| **新版協議沿用舊同意紀錄** | 有舊紀錄的裝置不會再次看到同意畫面。新裝置則在同意前就會建立含 OpenID 的用戶資料。前端先記下同意，再呼叫伺服器，即使寫入失敗也會繼續。[同意元件](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/miniprogram/components/privacy-modal/index.js#L4) · [啟動流程](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/miniprogram/app.js#L10) |

另外有三處文件需要對齊：

- **協商部分退款。** 澄清清單和部署說明已寫明「協商後可退部分金額並結案」，測試也通過。但用戶協議仍寫「已使用的場地、已核銷的券不再退款」，需求規格則寫「同一卡片可多次退款」，兩處都沒有寫明協商結案的例外。**這是文件矛盾，協商退款功能本身符合你定下的規則。** [澄清清單](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/docs/03-澄清清單.md#L93) · [用戶協議](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/miniprogram/utils/legal.js#L53)
- **資料保存與刪除。** 隱私政策承諾訂單到期刪除或匿名化、日誌到期刪除。任務清單仍列三年交易資料清理為待辦，我也未找到對應的日誌清理任務。政策裡的聯絡方式目前仍是空值。[隱私政策](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/miniprogram/utils/legal.js#L154) · [待辦規劃](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/docs/05-任務清單.md#L187)
- **支付部署。** 任務清單寫要把「商戶號和密鑰」填入環境變數，但目前支付程式讀取的是 `MCH_ID` 和 `PAY_MODE`，部署說明要求在微信後台完成授權。這兩份指引應統一，避免部署時誤填密鑰。[任務清單](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/docs/05-任務清單.md#L181) · [支付部署說明](https://github.com/MERCURY2203/feixiang-booking/blob/7d7b5a2/docs/部署與測試.md#L46)

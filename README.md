# 飞翔球馆 · 订场小程序

飛翔羽毛球館（10 個場地）的微信訂場小程序，客人端與管理端在同一個小程序內。經營方：廣州羽美體育發展有限公司。

本項目以 **SDD（規格驅動開發）** 方式開發：**`docs/` 裡的規格文件是唯一真相**，程式照文件寫；要改功能，先改文件、再改程式。

## 文件

| 文件 | 內容 |
| --- | --- |
| [01-立項書](docs/01-立項書.md) | 為什麼做、範圍、項目原則、已定案的關鍵規則 |
| [02-需求規格書](docs/02-需求規格書.md) | 每個頁面的內容、按鍵、操作結果和驗收標準 |
| [03-澄清清單](docs/03-澄清清單.md) | 規格中矛盾、模糊、遺漏之處的定案記錄 |
| [04-技術方案書](docs/04-技術方案書.md) | 架構、數據表、關鍵機制、畫面風格、上線準備 |
| [05-任務清單](docs/05-任務清單.md) | 25 個開發任務，按順序做，每個附完成標準 |
| [部署與測試-階段1](docs/部署與測試-階段1.md) | 階段 1（T1–T4）怎麼上傳、初始化、綁定老闆、逐項測試 |

## 技術

- 微信小程序 + 微信雲開發（雲函數、雲數據庫、雲存儲、定時任務）
- 微信支付；企業微信群機器人通知

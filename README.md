# 飞翔球馆 · 订场小程序

飛翔羽毛球館（10 個場地）的微信訂場小程序，客人端與管理端在同一個小程序內。經營方：廣州羽美體育發展有限公司。

本項目以 **SDD（規格驅動開發）** 方式開發：**`docs/` 裡的規格文件是唯一真相**，程式照文件寫；要改功能，先改文件、再改程式。

## 技術

- 微信小程序 + 微信雲開發（雲函數、雲數據庫、雲存儲、定時任務）
- 微信支付；企業微信群機器人通知

## 目錄

```
docs/                     規格文件、部署與測試說明
miniprogram/              小程序前端（WXML／WXSS／JS）
  pages/                  客人端頁面；pages/admin/ 為管理端
  components/             訂場表格、購物車浮窗、協議彈窗等
  utils/                  金額格式化、伺服器時間、購物車、結算流程
cloudfunctions/           雲函數（user、staff、booking、admin、payNotify、timer、initdb）
  _shared/                公共代碼（不上傳），用 scripts/sync-shared.js 複製到各函數 lib/
scripts/                  輔助腳本
tests/                    自動回歸測試（node tests/run.js），用假的雲開發環境跑真實雲函數代碼
```
